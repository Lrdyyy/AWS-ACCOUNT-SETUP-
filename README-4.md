## Introducing Today's Project!

Setting up an AWS account. Setup budget alerts and added additional MFA.

### Key tools and concepts

They key concepts I learned in this project were on the Identity access management side and the security side (MFA)

### Challenges and wins

This project took me approximately less than 15 minutes

## Creating My AWS Account

Create a an account with root access

### Understanding the root user

Root user is the highest privileged account in a system. A strong password is required for it security

## Setting Up Billing and Payment

In this step I chose the type of plan the account will have, in which I chose a free tier.

### Why AWS requires a payment method

It requires a free tier to show that the one who is using is a real person and can be billed once the free tier limit has been reached

## Completing Account Activation

In this step, its verifiying my identity and choosiing a support plan

### Identity verification and support plan

I verified my identity through the email verfiication. The basic support includes 24x7 self-service access to aws services. access to personal health dashboard and trusted advisor

## Enabling Free Tier Alerts

In this step, I setup budget alerts so that I will be notified if Im nearing my free tier cap

![Enabling Free Tier Alerts](https://nextwork.ai/hl-2/uploads/90e42921-e1f4-5c44-8a1f-394b21d79093_j6k1l7m3)

### Why usage alerts matter

They are useful as they notify you of what your are spending. This is to prevent unwanted purchases and budgetting errors

## Securing the Account with MFA

To enable MFA, I navigated to IAM dashboard, there will be a button there that would specify if the account has mfa or not. If it still has no mfa, just click the button and follow the instructions. The authenticator app sends codes to your registered device and you must input the code before logging in
